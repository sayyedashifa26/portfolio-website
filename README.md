## 👋 About This Project

This is my personal portfolio website built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks, no templates. I wanted full control over every animation, interaction, and design detail, so I wrote everything by hand.

The goal was to build something that actually represents who I am as a developer — clean, functional, and a little fun.

## 🛠️ Built With


- **Zero dependencies** — no npm, no bundlers, no frameworks
- **Vanilla JS** for all physics animations and interactions
- **CSS custom properties** for consistent theming throughout
- **Google Fonts** — Syne, Inter, JetBrains Mono

---

## ✨ Features

- **Physics-based tech stack** — balls fall, bounce, and cluster using a custom animation loop with gravity, friction, and bounce constants
- **Auto-scrolling marquees** — infinite scroll for both the projects section and the books section
- **AI Chatbot** — integrated Claude API assistant that can answer questions about my background and general tech topics
- **Blended avatar** — CSS `mix-blend-mode: multiply` to seamlessly blend the illustration with the background
- **Floating code badges** — animated code snippets orbiting the about section image
- **Fully responsive** — mobile-first, tested across all screen sizes
- **Smooth scroll animations** — intersection observer triggers fade-in animations as you scroll
- **Fixed resume button** — always-visible floating pill button

## 🎨 Design Decisions

| Decision | Reason |
|---|---|
| Burgundy `#800020` as brand color | Distinctive, professional, not the typical blue |
| Syne font for headings | Strong geometric personality, stands out |
| Single HTML file | Simpler deployment, no build step needed |
| Inline SVG icons | No CDN dependency, works offline |
| CSS mix-blend-mode for avatar | Cleaner than manual background removal |
| Vanilla JS physics | More control and learning than using a library |
